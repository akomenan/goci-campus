# PROTTECTOR

Prototype MVP (Expo / React Native / TypeScript) — super-app étudiante pour la Côte d'Ivoire.

## Fonctionnalités

- Accueil : salutations, alertes, raccourcis, todos
- Logement : liste, détail, publier stub, mes annonces
- Stages et jobs : filtres Stage/Job/Alternance, détail, postuler, mes candidatures
- **Univs / Nouveaux bacheliers** : annuaire des universités (publique / privée), recherche, détail + contact (tél / email / site)
- Profil : nom, ville, univ, filière, niveau
- UI française, mock Abidjan, thème teal #0D9488

## Prérequis

- Node.js 20+
- Expo Go sur Android ou iOS

## Installation

```bash
cd estudy-world
npm install
```

## Lancer

```bash
npx expo start
```

Scannez le QR code avec Expo Go.

## TypeScript

```bash
npx tsc --noEmit
```

## Notes

Prototype local sans backend. Les infos universités sont indicatives — à vérifier sur les sites officiels.
